# Что не сделано

## Ждёт проверки на реальной Windows

- [ ] Выполнить `install.ps1` (без админа) и открыть **новое** окно терминала (иначе не виден обновлённый `PATH`).
- [ ] Прогнать `-Doctor`, `-SelfTest`, `-Status`, `claude --version` и обе живые проверки
      (`ru-exit`, `region`) — только на самой Windows.
- [ ] Проверить Windows-специфичное, что не покрывается эмуляцией (`Get-NetAdapter`,
      `Find-NetRoute`, Планировщик задач, порядок `PATH` в реестре, ярлык «Claude (с VPN)»).
- [ ] Убедиться, что сторож действительно гасит Claude при обрыве VPN (с подсадной уткой
      или на коротком реальном обрыве), и что `--dry-run` показывает верных кандидатов.

## Ветка Linux/WSL

- [ ] Проверить установку `linux/install.sh` внутри WSL (в т.ч. `--no-systemd`), если Claude
      Code там стоит.
- [ ] Если Claude Desktop в WSL нет — помнить, что 4-я проверка будет пустой (это норма).
