# От чего защищаем и от чего — нет

## Угроза

Anthropic не обслуживает РФ. Если запрос уходит с российского IP, аккаунт попадает под
блокировку по региону — вплоть до бана. Отдельный случай: выход VPN формально не РФ
(например, датацентровый США), но **бэкенд Anthropic считает регион неподдерживаемым**
(`region_unavailable`) — тогда Claude Desktop висит на экране «неподдерживаемая страна»,
OAuth/bootstrap отвечают 403, и повторные попытки с того же выхода только копят негатив.

Значит, недостаточно «поднять VPN»: нужно (а) не выпустить трафик мимо туннеля и
(б) не долбиться с выхода, который Anthropic уже отверг.

## Что покрыто

| Канал | Чем закрыт |
|---|---|
| Claude Code в терминале | обёртка/шим вместо бинаря — проверка **до** запуска процесса |
| Claude Desktop (GUI) | ярлык через `claude-desktop-guard` + сторож во время работы |
| «Туннель отвалился на ходу» | сторож: 2 провала (~30 с) → гашение |
| «Туннель есть, а выход РФ» | проверка страны двумя путями, сторож вызывает полную проверку |
| «IPv4 идёт в туннель, а IPv6 — напрямую» | проверка глобального маршрута `::/0` мимо туннеля (шаг 3) |
| «Выход формально не РФ, но Anthropic отверг» | проверка вердикта Anthropic (шаг 5) + память плохих выходов |
| «npm-обновление сняло защиту» | самолечение (таймер / задача Планировщика) |
| Аварийный ручной обход | `CLAUDE_GUARD_OVERRIDE=1` — только вручную, пишется в лог |

## Что НЕ покрыто (остаточные риски)

- **Расширение Claude Code для VS Code** — стражем не перехватывается. Защищено только
  тем, что трафик идёт через TUN (сплит-правила отправляют домены Anthropic в туннель).
  Если туннель отвалится между запусками расширения — расширение продолжит работать
  до срабатывания сторожа (сторож закрывает и процессы Code).
- **Claude Desktop из Microsoft Store (MSIX)** перехватить перехватчиком нельзя:
  от запуска защищает только ярлык «Claude (с VPN)», а после запуска — сторож.
  Кто запустит приложение другим способом, получит проверку лишь постфактум.
- **Ваши собственные приложения, использующие Anthropic API** (свои бэкенды, прокси,
  скрипты) этим комплектом не закрыты — у них своя маршрутизация и свой контроль.
  Комплект отвечает только за Claude Code и Claude Desktop.
- **Другие каналы утечки IP вне Anthropic** (браузер, claude.ai, мобильные клиенты) —
  не тема этого проекта: Happ TUN закрывает маршрут и DNS для системы, но это настройка
  VPN, а не стража.
- **Утечка DNS мимо VPN на уровне прокси-клиента.** Шаг 3 ловит глобальный маршрут IPv6
  (весь трафик такого маршрута), но DNS-запросы, ушедшие через системный резолвер по
  правилам сплита, стражем не видны — это область настройки VPN-клиента.
- **Логи Desktop как источник вердикта.** Если Desktop не запускался ни разу, жалоб нет —
  проверка вердикта молча пропускает (шаги 1–4 при этом работают). В WSL без установленного
  Desktop та же ситуация: региональная проверка пуста.
- **Ложные срабатывания.** Сторож может закрыть работающий Claude при переподключении
  VPN дольше ~30 с; черновики в Desktop при этом теряются — это осознанный выбор в пользу
  «не выйти из РФ молча». Пометка выхода в `web-blocked-ips` живёт до смены IP: если VPN
  выдал тот же адрес снова, блокировка вернётся (лечится `--reset-web-block`).

## Принцип

**Fail-closed:** сомнение трактуется как запрет. Дешевле разобраться, почему страж
отказал, чем объяснять Anthropic, почему с аккаунта месяцами ходили запросы из РФ.
